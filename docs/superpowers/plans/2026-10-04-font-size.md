# Font Size Setting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Config gets a FONT setting, Normal (6×8) or Large (12×16). Opted-in text apps opened after the change draw at that size, in windows grown to fit.

**Architecture:**
- The kernel holds a `font_scale` setting (1 or 2). At spawn it reads the app's manifest once, for both the cart flag and the new `font = scalable` opt-in, and fixes a per-window scale. Opted-in built-in apps get the setting; everything else gets 1. A scale-2 window's size is doubled (title bar excepted), clamped to the screen, and its position is clamped on screen.
- `acid_draw_text` draws at the window's scale through a new `Canvas::draw_text_scaled`. Window chrome stays at scale 1.
- Apps read `acid_font_size()` and `acid_window_size()` at load and derive all their layout numbers from them.

**Tech Stack:** Rust 2024 workspace (`v3/`), mlua 0.10 (Lua 5.4), wasmi 2.

**Spec:** `docs/superpowers/specs/2026-10-04-font-size-design.md`

## Global Constraints

- **Repo and branch:** `/home/norfolkh/acid-os-v3`, branch `font-size` (it already has the spec commit). Run commands from the repo root.
- **Full suite:** `cargo test --manifest-path v3/Cargo.toml --workspace -q`. Baseline is 409 passing. Every task ends with the whole suite green and no compiler warnings.
- **Scales:** 1 (Normal) or 2 (Large). Character cell is `6·scale × 8·scale`. `TITLE_BAR_H` = 16 and `DESKTOP_STRIP_H` = 24 are unchanged.
- **Window growth at scale `s`:** `w' = min(screen.w, w·s)` and `h' = min(screen.h − 24, max(h, 16 + (h − 16)·s))`. Scale 1 changes nothing: size, position and behaviour stay byte-identical to today.
- **Who opts in:** the manifest key `font = scalable`. The key is matched case-insensitively. The value is trimmed and quote-stripped, then must be exactly `scalable`. It is honoured only for built-in (not cart-level) apps.
- **Opted-in apps, with Normal → Large window at 640×480:**
  - Terminal 260×160 → 520×304;
  - Editor 420×280 → 640×456;
  - File Manager 220×160 → 440×304;
  - System Monitor 200×160 → 400×304;
  - About 180×150 → 360×284;
  - Network 200×110 → 400×204.
- **Never opted in:** desktop, Config, games, Load Cart, hello_acid, carts.
- **Normal is unchanged:** at Normal, every derived layout value equals the app's current constant, and existing Lua suites keep their expected values.
- **Test fakes:** `AcidApi` fakes return `font_size` (6, 8), `font_scale` 1, and a fixed `window_size`. Getters do not log. `set_font_scale` logs `font_scale <n>`.

```rust
/// A window's size when its app draws at `scale`: the text area below the
/// title bar grows by `scale` in both directions (the title bar doesn't),
/// clamped to the screen less the desktop strip. Scale 1 is the size itself.
pub fn grown_size(screen: Screen, w: i32, h: i32, scale: i32) -> (i32, i32) {
    if scale <= 1 {
        return (w, h);
    }
    let w2 = (w * scale).min(screen.w);
    let h2 = (TITLE_BAR_H + (h - TITLE_BAR_H) * scale).max(h).min(screen.h - DESKTOP_STRIP_H);
    (w2, h2)
}
```

```rust
/// What an app's own manifest says about it, from one read.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct ManifestFlags {
    /// Cart-level trust (spec §14.2).
    pub cart: bool,
    /// `font = scalable`: draws at Config's font size.
    pub scalable: bool,
}

pub fn manifest_flags(platform: &dyn Platform, script_path: &str) -> ManifestFlags {
    let outside = ManifestFlags { cart: true, scalable: false };
    if !(crate::fs_path::fs_path_is_allowed(script_path)
        && script_path.starts_with("v3/apps/")
        && script_path.ends_with(".lua"))
    {
        return outside;
    }
    let stem = &script_path[..script_path.len() - ".lua".len()];
    let toml = alloc::format!("{stem}.app.toml");
    match platform.fs().read(&toml) {
        Ok(bytes) => {
            let fields = crate::manifest::parse_manifest(&String::from_utf8_lossy(&bytes));
            // Any spelling of the key counts (`Source`, `SOURCE`): fail closed.
            let has = |key: &str, want: &str| fields.iter().any(|(k, v)| k.eq_ignore_ascii_case(key) && unquote(v) == want);
            ManifestFlags { cart: has("source", "cart"), scalable: has("font", "scalable") }
        }
        Err(acid_platform::FsError::NotFound) => ManifestFlags { cart: false, scalable: false },
        Err(_) => outside,
    }
}

pub fn app_is_cart(platform: &dyn Platform, script_path: &str) -> bool {
    manifest_flags(platform, script_path).cart
}
```
